# Ankit Kumar - AI/ML Engineer & Full Stack Developer Portfolio

A modern, high-performance, and interactive developer portfolio showcasing AI/ML projects, full-stack systems, technical research, and production applications.

Live Demo: [View Portfolio](https://github.com/ankitkgupta11-g)

---

## 🚀 Key Features

- **Split Screen Layout**: Persistent identity dashboard on the left paired with an interactive work showcase on the right.
- **Interactive 3D Neural Core**: Real-time Three.js neural sphere simulation with dynamic physics and particle field.
- **Projects & Work**: Comprehensive filterable project showcases with live links, GitHub repos, technical metrics, and architectural breakdowns.
- **Live Terminal (AnkitOS)**: Interactive CLI emulator supporting commands (`help`, `projects`, `skills`, `contact`, `whoami`, `clear`, etc.).
- **Recruiter Scan Mode**: Single-click ATS-optimized, high-density summary view for rapid recruiter evaluation.
- **Interactive Tech Stack**: Filterable technology grid covering AI/ML, Backend, Frontend, Cloud & DevOps, and Databases.
- **AI Neural Voice/Sound Engine**: Synthesized web audio feedback for high-tech micro-interactions (with mute toggle).
- **SEO & Social Cards**: Fully compliant JSON-LD structured schema (`Person`), OpenGraph tags, and Twitter Cards.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4
- **Animations**: Motion (`motion/react`)
- **3D Graphics**: Three.js
- **Icons**: Lucide React
- **Build Tool**: Vite

## 💻 Getting Started Locally

### Prerequisites

- Node.js 18+ or 20+
- npm, pnpm, or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/ankitkgupta11-g/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:3000` (or the port specified in terminal).

### Building for Production

```bash
npm run build
```

The static output will be in the `dist/` directory ready for deployment on Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
